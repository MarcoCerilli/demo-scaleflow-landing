# ScaleFlow Studio | High-Conversion Engineering Agency

Landing page ad alta conversione con calcolatore ROI dinamico in tempo reale, funnel di qualificazione lead a 3 step e piani tariffari trasparenti.

## 🚀 Guida Rapida Deploy su Vercel

Questo progetto è un'applicazione React + Vite + Tailwind CSS autonoma e indipendente al 100%, pronta per essere caricata su una repository GitHub dedicata e pubblicata su Vercel.

### 1. Esegui in Locale
```bash
npm install
npm run dev
```

### 2. Build di Produzione
```bash
npm run build
```

### 3. Pubblicazione su GitHub & Vercel
1. Crea una nuova repository su GitHub: `https://github.com/new` (es. `scaleflow-landing-demo`).
2. Inizializza Git e carica il codice:
```bash
git init
git add .
git commit -m "feat: initial commit for ScaleFlow Studio | High-Conversion Engineering Agency"
git branch -M main
git remote add origin https://github.com/TUO-USERNAME/scaleflow-landing-demo.git
git push -u origin main
```
3. Vai su [Vercel](https://vercel.com/new), importa la repository e clicca **Deploy**.
